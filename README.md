# 와이파이 정보 구하기

이 프로젝트는 공공 와이파이 정보를 수집하고 웹 애플리케이션을 통해 사용자에게 제공하는 것을 목표로 합니다.

## 기능

- 공공 와이파이 정보를 데이터베이스에 저장
- 사용자가 현재 위치 주변의 와이파이 정보를 검색 가능
- 와이파이 상세 정보 제공
- 사용자가 원하는 위치의 와이파이 정보 검색 가능

## 기술 스택

- Java
- JavaServer Pages (JSP)
- JDBC
- MySQL
- HTML/CSS/JavaScript

## 과제 시나리오

"내 위치 기반 공공 와이파이 정보를 제공하는 웹서비스 개발"

- 수행 목적: 주어진 과제를 통하여 학습한 자바와 웹 그리고 데이터베이스의 개념과 이를 통한
응용을 통하여 스킬 업을 하고자 함. 또한, 기본 데이터베이스 개념을 개발로 연동해 보지
않은 데이터베이스(SQLite)에 대해서 수행할 수 있는 기능을 배양하고자 함.
타 시스템 호출(Open API)를 호출하는 문제 해결 능력을 키우고자 함.

- 간략 소개: 공공 데이터 자원을 활용하여 내가 서비스 하고자 하는 데이터로
아이그레이션하여 웹을 기반으로 하여 원하는 형태로 출력하고자 함. 또한, 사용한 히스토리에
대해서 데이터베이스에 저장하는 기능과 이를 출력할 수 있도록 구현하고자 함.
